 Procurement Data Analysis (EDA)

 Project Overview
This project performs Exploratory Data Analysis (EDA) on procurement data to understand spending patterns across departments, vendors, and geographic areas.

🔍 Key Analysis
- Department-wise spend analysis
- Cost center analysis
- Vendor analysis
- Geographic area analysis
- Correlation analysis

📈 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

💡 Key Insights
- Spending is concentrated in a few departments and cost centers
- Contract-based procurement dominates
- Local vendors contribute most of the spending
- Weak correlation between quantity and cost

 📌 Conclusion
The analysis highlights the need for better cost control and strategic procurement planning.
